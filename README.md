# Neon Blaster

Um jogo arcade de nave em React + Canvas, com estética neon/cyberpunk: partículas de explosão, combos, power-ups, som procedural (Web Audio API, sem arquivos externos) e recorde salvo no navegador.

## Como jogar

- **Mover:** setas / WASD, ou arraste o dedo na tela (touch)
- **Atirar:** espaço, ou toque na tela (auto-fire enquanto tocar)
- **Pausar:** Esc
- **Mudo:** M

Destrua inimigos para ganhar pontos e combos. De vez em quando eles soltam power-ups:

- 🟡 **Rápido** — cadência de tiro dobrada
- 🔵 **Triplo** — tiro em leque (3 direções)
- 🟢 **Escudo** — invencibilidade temporária
- 🔴 **+1** — vida extra

O jogo fica mais difícil a cada nível: inimigos mais rápidos, mais variados e com mais vida.
